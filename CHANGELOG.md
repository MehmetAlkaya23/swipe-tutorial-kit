# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-09-22

### Added

- `SwipeTutorial`: drop-in overlay that shows once and remembers completion.
- `SwipeTutorialOverlay`: the presentational overlay, for full control.
- `useSwipeTutorial`: persistence hook with versioning, `show`, `reset` and error reporting.
- `createMemoryStorage`: in-memory storage for tests and previews.
- Reduce Motion support, screen reader summary, custom card rendering, theming and timing overrides.
